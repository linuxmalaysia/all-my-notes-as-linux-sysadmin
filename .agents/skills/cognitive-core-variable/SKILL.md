# 🧠 Pengekstrak Pemboleh Ubah Teras

## Bilakah kemahiran ini patut digunakan?
Gunakan kemahiran ini apabila sesuatu permasalahan atau sistem dirasakan terlalu rumit, sarat dengan butiran, atau mengelirukan.

## Apakah fungsi kemahiran ini?
Kemahiran ini akan menyaring maklumat untuk mengenal pasti beberapa faktor atau pemboleh ubah terpenting sahaja yang secara kritikal mempengaruhi atau menentukan hasil keseluruhan.
