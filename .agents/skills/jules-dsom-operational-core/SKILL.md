# Teras Operasi Google Jules (Jules Knowledge Base)

## Tujuan Kemahiran
Kemahiran ini bertindak sebagai "jambatan memori" (memory bridge) antara Google Jules dan Google Antigravity. Ia merangkum keseluruhan kefahaman operasi Jules mengenai projek NOSS Linux Malaysia dari "Hari ke-0".

## 1. Protokol Deep State of Mind (DSOM)
Jules memahami bahawa repositori ini tidak sekadar menyimpan kod, tetapi beroperasi sebagai **Sovereign Markdown Palace**.
- Segala fail silibus (Topik) disimpan dalam `openwiki/`
- Segala fail kemahiran amali dan teknikal (AgentSkills) disimpan dalam `.agents/skills/`
- Setiap agen WAJIB mematuhi peraturan dalam `.agents/AGENTS.md` (AI Constitution).

## 2. Pematuhan Format YAML (OKF + Antigravity)
- Setiap kemahiran mesti bermula dengan metadata YAML yang sah untuk membolehkan penemuan (discovery) oleh enjin Google Antigravity dan OpenSkills (berasaskan spesifikasi [AgentSkills.io](https://agentskills.io/home) dan [Google Antigravity](https://antigravity.google/docs/skills)).
- Metadata wajib: `okf_version`, `name`, `description`, `topics`, `tags`, `type`.

Setiap pemprosesan dokumen diakhiri secara mandatori dengan:

## 4. Tatacara Pemasangan Linux Pejabat (The "Canonical" Rule)
Jules sentiasa mengingati bahawa:
- Sasaran Lalai Desktop: **Ubuntu 26.04 LTS "Resolute Raccoon"**
- Sasaran Lalai Pelayan / Perusahaan: **AlmaLinux 10 "Purple Lion"**
- Semua peranti perusahaan diwajibkan menggunakan penyulitan **LUKS2 FDE** secara automatik.
