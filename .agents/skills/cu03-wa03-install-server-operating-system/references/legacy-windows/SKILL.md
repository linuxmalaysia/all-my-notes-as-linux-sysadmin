# Work Activity Summary
This skill governs the execution of INSTALL SERVER OPERATING SYSTEMS. to produce functional operational outputs according to enterprise quality standards.

## Required Utilities & Prerequisites
*   **System Commands:** standard windows utilities
*   **Hardware / Equipment:** Laptops (1:1), Desktops (1:1), Network firewall (1:1), Network router & switch (1:5), Wireless access point (1:5), Server machine / virtualisation host (1:5), Network equipment rack (1:5), KVM switch (1:5), UPS (1:5), NAS / network backup storage (1:2)
*   **Tools:** Screwdrivers (Philips & Flathead), Crimping tools, Punch down tools, Pliers and pry tools, Anti-static wrist straps, ESD mats, Multimeters, Cable testers
*   **Materials:** RJ45 connectors, Cat5e/Cat6 cables, Cable ties, Labels, Thermal paste
*   **Documentation:** organizational SOPs, vendor manuals

## Core Execution Steps (Work Steps)
*   **Step 3.1:** Prepare OS media.
*   **Step 3.2:** Deploy operating system.
*   **Step 3.3:** Configure server identity.
*   **Step 3.4:** Update system patches.
*   **Step 3.5:** Configure access control.

## Performance Criteria (Quality Gates)
> Note: For full compliance checklists, refer to the Compliance archive.

*   Approved operating system installation media and server firmware boot sequences prepared.
*   Operating system software installation, core storage partition layouts, and software licensing activation deployed.
*   Server hostname identity, network addressing parameters, and logical connectivity statuses configured.
*   Approved operating system security patches, software updates, and maintenance system utilities updated.
*   Administrative user accounts, secure authentication policies, and host-level firewall rules configured.
