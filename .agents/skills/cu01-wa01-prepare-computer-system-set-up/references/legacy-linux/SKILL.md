# Work Activity Summary
This skill governs the execution of PREPARE COMPUTER SYSTEM SET-UP. to produce functional operational outputs according to enterprise quality standards.

## Required Utilities & Prerequisites
*   **System Commands:** standard linux utilities
*   **Hardware / Equipment:** Laptops (1:1), Desktops (1:1)
*   **Tools:** Screwdrivers (Philips & Flathead), Crimping tools, Punch down tools, Pliers and pry tools, Anti-static wrist straps, ESD mats, Multimeters, Cable testers
*   **Materials:** RJ45 connectors, Cat5e/Cat6 cables, Cable ties, Labels, Thermal paste
*   **Documentation:** organizational SOPs, vendor manuals

## Core Execution Steps (Work Steps)
*   **Step 1.1:** Identify setup requirements.
*   **Step 1.2:** Inspect computer components.
*   **Step 1.3:** Prepare assembly tools.
*   **Step 1.4:** Verify component functionality.
*   **Step 1.5:** Report preparation outcomes.

## Performance Criteria (Quality Gates)
> Note: For full compliance checklists, refer to the Compliance archive.

*   Computer set-up requirements and hardware compatibility determined.
*   Computer components visually examined for damage.
*   Workstation and required assembly tools set.
*   Core component functionality and BIOS POST statuses confirmed.
*   Preparation outcomes and component test results documented.
