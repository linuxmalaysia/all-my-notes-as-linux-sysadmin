### **CU 01: Deploy Endpoint Devices Configuration** *Unit Code: IT-020-3:2026-CU01*

* **L3-C01-W01**: Install and configure endpoint devices.
* **L3-C01-W02**: Install and configure Operating Systems.
* **L3-C01-W03**: Install peripherals and verify hardware functionality.
* **L3-C01-W04**: Install and configure standard application software.

### **CU 02: Provide End User Services Support Procedure** *Unit Code: IT-020-3:2026-CU02*

* **L3-C02-W01**: Prepare end user support service requirements and resources.
* **L3-C02-W02**: Handle end user service requests and support communication.
* **L3-C02-W03**: Provide technical assistance and basic troubleshooting support.
* **L3-C02-W04**: Perform basic troubleshooting and issue escalation activities.
* **L3-C02-W05**: Maintain end user support records, reports and service documentation.

### **CU 03: Support IT Devices and Connectivity Access** *Unit Code: IT-020-3:2026-CU03*

* **L3-C03-W01**: Prepare computer device, SaaS application and connectivity support requirements.
* **L3-C03-W02**: Support computer devices hardware, software and peripheral operations.
* **L3-C03-W03**: Support SaaS applications access, configuration and user assistance.
* **L3-C03-W04**: Configure and troubleshoot basic network and connectivity issues.
* **L3-C03-W05**: Maintain support records, updates and basic system maintenance.

### **CU 04: Operate Virtualization and SaaS Environment** *Unit Code: IT-020-3:2026-CU04*

* **L3-C04-W01**: Prepare server and virtual machine requirements.
* **L3-C04-W02**: Operate and manage basic server systems and services.
* **L3-C04-W03**: Configure and manage virtual machine environments.
* **L3-C04-W04**: Operate basic cloud resources, storage and connectivity services.
* **L3-C04-W05**: Perform monitoring, maintenance and troubleshooting for server, virtual machine and cloud resources.

### **CU 05: Perform Cyber Security Hygiene Practices** *Unit Code: IT-020-3:2026-CU05*

* **L3-C05-W01**: Prepare identity, access and endpoint security operational requirements.
* **L3-C05-W02**: Configure and manage user identity, authentication and access control settings.
* **L3-C05-W03**: Perform endpoint security configuration and cyber hygiene practices.
* **L3-C05-W04**: Conduct basic security checks, monitoring and vulnerability verification.
* **L3-C05-W05**: Maintain security records, incident reporting and compliance documentation.

### **CU 06: Verify Alerts and Troubleshooting** *Unit Code: IT-020-3:2026-CU06*

* **L3-C06-W01**: Prepare monitoring, backup, recovery and automation operational requirements.
* **L3-C06-W02**: Verify monitoring alerts and system operational status.
* **L3-C06-W03**: Verify backup status and perform basic recovery activities.
* **L3-C06-W04**: Execute automation scripts and scheduled tasks.
* **L3-C06-W05**: Maintain monitoring, backup and recovery documentation and reports.
