# Topik 1: Pengenalan & Asas Meja Linux (CU01)

## Overview (Gambaran Keseluruhan)
Topik ini menyediakan pemahaman asas mengenai cara pemasangan, tatarajah awal, dan penggunaan sistem operasi meja (Desktop) Linux. Ia merupakan pemetaan langsung daripada struktur kemahiran **CU01 (Computer System Set-up)** NOSS Tahap 3.

## Silibus Utama
1. **Linux Desktop Environments**: GNOME, KDE Plasma, XFCE.
2. **Pemasangan OS**: *Bootable USB (Rufus / BalenaEtcher)*, proses *partition* awal, penciptaan profil pengguna.
3. **Linux File System Hierarchy (FHS)**:
   - `/` (Root)
   - `/home` (Pengguna biasa)
   - `/etc` (Fail konfigurasi)
   - `/var` (Data pelbagai saiz seperti log)
4. **Basic Command Line & Package Management**:
   - Kemas kini perisian (`apt update && apt upgrade` atau `yum update`).
   - Pemasangan perisian pejabat dan pemacu (drivers).
