# Direktori Perisian Alternatif (Linux vs Windows)

Salah satu kegusaran utama bagi pengguna baharu adalah ketidakpastian mengenai keberadaan perisian pejabat yang setara dengan Windows. Berikut adalah jadual padanan perisian yang disediakan sebagai panduan asas.

## Jadual Perbandingan Perisian

| Kategori | Perisian Linux | Perisian Windows |
| :--- | :--- | :--- |
| **Lukisan Kejuruteraan (CAD)** | VariCAD, LinuxCAD, FreeCAD | AutoCAD, IntelliCAD |
| **Sistem Pangkalan Data (RDBMS)** | MySQL, PostgreSQL, MariaDB, Oracle | MS Access, MS SQL Server, Oracle |
| **Penterjemah Arahan (Shell)** | BASH, zsh, csh | Command Prompt, PowerShell |
| **Penyunting Teks (CLI)** | vim, nano (pico) | Edit |
| **Penyunting Teks (GUI)** | gEdit, Kate | Notepad, WordPad |
| **Pelayar Web** | Mozilla Firefox, Google Chrome, Opera | MS Edge, Google Chrome |
| **Pemain Multimedia** | VLC, MPV, Rhythmbox | Windows Media Player |
| **Utiliti Pemampat Fail** | gzip, bzip2, xz, tar | WinZip, WinRAR |
| **Aplikasi FTP** | FileZilla, vsftpd | FileZilla, CuteFTP |



## Pautan Sumber Komuniti & Dokumentasi

- **The Linux Documentation Project (TLDP)**: Arkib terbesar panduan HOWTO.
- **JustLinux**: Komuniti bantuan forum yang aktif.
- **Linux.org**: Pangkalan maklumat asas dan senarai edaran (distros) terkini.
