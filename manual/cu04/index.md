# CU04: Automasi, Sandaran & Pemulihan Sistem

## 📖 Pengenalan Unit Kompetensi
Modul NOSS Level 3 merangkumi alatan sandaran, automasi skrip shell, cron jobs, dan prosedur pemulihan bencana (Disaster Recovery).

---

## 📑 Senarai Aktiviti Kerja (Work Activities - WA)

- [**Persediaan Alatan Sandaran & Pemulihan**](cu04-wa01-persediaan-alatan-sandaran-dan-pemulihan.md) — *Pemilihan utiliti sandaran Linux (rsync, BorgBackup, Restic, tar) dan media storan.*
- [**Pelaksanaan Operasi Sandaran Tempatan**](cu04-wa02-operasi-sandaran-tempatan.md) — *Automasi skrip sandaran data tempatan menggunakan Bash dan systemd timers / cron.*
- [**Operasi Sandaran Berasaskan Rangkaian & Awan**](cu04-wa03-sandaran-berasaskan-rangkaian.md) — *Konfigurasi sandaran selamat melalui SSH/SFTP dan penyegerakan ke storan NAS/Cloud Object Storage.*
- [**Pemulihan Data & Sistem Fail**](cu04-wa04-pemulihan-data-dan-sistem-fail.md) — *Prosedur verifikasi integriti integriti sandaran dan pemulihan data terpilih.*
- [**Pemulihan Menyeluruh Bare-Metal Endpoint**](cu04-wa05-pemulihan-bare-metal-endpoint.md) — *Prosedur pemulihan imej sistem menyeluruh menggunakan Rescue Live USB dan Clonezilla.*
